# Optional evaluation

Run this protocol only when evaluation is requested and authorized reference material is available. Do not change generation inputs after seeing evaluation results without recording a new configuration.

## Distinct evaluation targets

| Target | Evidence | Interpretation |
|---|---|---|
| Reference-claim coverage | Expert reference and a fixed claim inventory | Coverage of that reference, not exhaustive coverage of legally material source facts |
| Source support | Original judgment passages | Whether a generated claim is supported, including attribution and qualifications |
| Structural compliance | Explicit format/scope rules and implemented checks | Compliance with those rules, not overall correctness |
| Rubric quality | Anchored dimension scores | Usability-oriented assessments under the specified judges |
| Practitioner preference | A documented human comparison protocol | Preference under that protocol, not legal safety or deployment effectiveness |

Persist predicted claims, the reference-claim inventory, matching decisions, source-support assessments, missing-claim severity, rubric records, and aggregation settings. A valid citation marker and a semantically supported citation are different outcomes. Track uncited factual statements separately.

The LENS rubric has 14 dimensions: fluency, redundancy, coherence, timeline clarity, compliance, accessibility, reasoning completeness, uncertainty calibration, coverage, precision, terminology, structure, scope and reasoning. Timeline clarity applies to Facts; reasoning completeness, structure and reasoning apply to Judicial reasoning. The other dimensions apply across sections. Use explicit anchored definitions before collecting scores; this list alone is not a calibrated scoring instrument.

For an adapted multi-judge evaluation, record the actual judges and missing scores. If following the applicability-corrected aggregation, take the median of valid judge scores for each applicable section-dimension item, average across applicable sections within each dimension, and then average the 14 dimensions. Do not count unrelated metadata as dimensions. Report missingness; do not impute absent judgments silently. Different judges or scoring anchors define a new evaluation configuration.

For inferential comparisons, identify the independent unit, paired cases, endpoint family, test choice and assumptions, direction, alpha, multiplicity policy, effect sizes, variability and actual P values. Use recorded original results; never infer missing P values from significance labels. Repeated judgments from the same dispute may not be independent. Human ratings require the appropriate actual ethics/consent arrangements and a protocol that accounts for repeated ratings.

This release contains no benchmark scores or practitioner ratings and does not reproduce the paper's analyses. Use the fictional example only to exercise the file contract, not to report accuracy or quality.
